# dnd-dice

Кидалка кубиков для D&D: d4, d6, d8, d10, d12, d20, d100, смешанные броски, бонус, преимущество/помеха, подсветка критов.

## Как получить APK

После каждой загрузки изменений GitHub сам собирает приложение (вкладка **Actions**).
Готовый файл: **Releases → latest → dnd-dice.apk**.

Страница приложения лежит в `app/src/main/assets/index.html` — чтобы что-то поменять, правь её.
