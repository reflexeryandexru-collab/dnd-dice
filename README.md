# dnd-dice

Бросок кубиков для D&D — одностраничное приложение (`index.html`), без зависимостей.

## Возможности
- Кубы d4, d6, d8, d10, d12, d20, d100 — любое количество каждого
- Бонус/модификатор (кнопки ± и быстрые значения)
- Преимущество и помеха для d20
- Подсветка натуральной 20 и натуральной 1
- Честный рандом через `crypto.getRandomValues`
- Удобно на телефоне, вибрация при броске

## Запуск
Просто откройте `index.html` в браузере.

Чтобы открыть с телефона по ссылке, включите GitHub Pages:
Settings → Pages → Source: Deploy from a branch → `main` / `(root)`.
